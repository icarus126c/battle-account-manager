战网账号管家 v1.14.2 · 自用 / 友情分享 / 赞助版

启动与升级
把整个压缩包解压到可写入的文件夹，双击“启动账号管家.exe”。不需要 Codex 或开发环境。
升级前正常关闭旧管家。本版沿用 %LOCALAPPDATA%\BattleAccountManager 的资料，无需复制旧版 data 文件夹。
不要只复制单个 EXE，也不要在压缩包里直接运行。首次使用自行添加账号。
建议 Windows 10 / 11；启动助手检查 .NET Framework 4.7.2 或更新版本及配套文件。
内置网页登录需要 WebView2 Runtime；也可以使用已安装的 Chrome / Edge。

本版调整
国服“网页登录”旁直接提供独立的“单独打开战网”按钮，无需展开登录选项。仅打开官方客户端，沿用当前地区及登录状态；网页登录准备仍使用旁边的按钮。
账号标题下方直接显示“复制登录邮箱（国服为登录账号）”“复制密码”“复制战网昵称”。登录邮箱来自编辑窗口的登录账号字段，昵称 / BattleTag 是另一项，不能当作登录邮箱使用。内容未填写时，点击“编辑账号”补充。
复制结果显示在按钮旁。剪贴板短暂被其他程序占用时会有限重试，仍失败时明确提示；成功复制后约 30 秒清理本软件复制的内容，锁定后不能复制。
三个发行版本共用登录核心。自用版和友情分享版无广告；赞助版的静态赞助卡片默认关闭。详见三版说明.txt。

修复国服一键登录被缺失的 AutoLoginCN 标记误拦截。国服区服和通用保持登录已确认时，允许沿用原登记尝试启动；明确关闭保持登录、区服不符或登记版本变化时仍会停止。不会补写登录开关，不会覆盖原登记；能否免认证仍以客户端结果为准。

外服切换组件超过等待时间但仍在运行时，保留备份和当前配置，不再立即撤回；组件结束前阻止再次切换及自动回写。
自动准备和手动选择登录窗口共用一套取消、超时与清理流程。浏览器或接管准备最多等待约 30 秒；即使底层初始化迟迟不返回，也能取消准备。
取消后丢弃过期结果，清理晚到的接管；本次尚未准备好的内置窗口会关闭，已有账号网页资料不删除。
战网显示启动画面时继续等待真正的登录窗口，不再在约 4 秒时误判失败；等待结束边界出现的登录窗口也能识别。
代码按登录协调、客户端适配、内置浏览器会话和界面操作拆分。账号存储格式、主密码/两步验证、账号标识、专用浏览器目录及登录选择登记保持兼容。
本轮验证使用虚构资料、受控异步任务和界面测试；没有切换真实战网账号或刷新服务端登录状态。

保留的功能
修复启动时区服检查跨线程更新窗口导致的闪退。窗口加载完成后再检查，检查结果统一交回界面线程；关闭窗口或切换账号后丢弃过期结果。
账号详情与编辑窗口统一显示“战网昵称 / BattleTag”，编辑窗口保留选填标注。
“网页登录”自动启动战网、等待登录窗口并准备所选账号的浏览器。已有登录窗口会直接使用，多个窗口时请自行指定。
等待战网登录窗口最多约 45 秒，之后准备浏览器和接管最多约 30 秒。可点“取消准备”；战网保持运行，未准备完成的本次内置窗口会关闭，浏览器资料保留。
战网已进入账号时不会自动退出登录。若打开的是外服登录页，请在官方客户端切到国服，再准备网页登录。
内置窗口准备时打开；Chrome / Edge 收到战网的新登录请求后自动打开。不会复用旧登录网址。
国服一键登录（实验）默认展开，打开软件即可看到按钮；仍可手动收起。
删除“启用国服一键切换”勾选，保留实验标注及战网退出检查。
“归档”改为“隐藏账号”，可从“已隐藏账号”找回；收藏按钮根据状态显示“收藏”或“取消收藏”。
登录结果反馈默认收起，只用于记录你看到的结果，不会发起登录。
登录操作放在账号信息下方；“账号与密码”“登录方式与备忘”默认收起，收起密码区域会立即隐藏明文。
“设置与备份”集中提供保护设置、完整备份与恢复、资料目录、战网位置和环境检查。
原“国服 / 外服入口”改名为“解锁外服客户端”，仍可补齐国服和外服的登录地区选项。
选中账号后只读检查战网保存的地区标记；可能不匹配时展开提示。也可手动展开“区服检查”刷新。
保存的地区可能与当前窗口不同，尤其是多开时。这项检查不会自动切换区服或判定服务器登录成功。
登录准备出错，或点击“没登进去，查看帮助”后，底部提供重新认证、检查区服、检查环境等按钮。
处理按钮由用户点击后才执行；不会自动反复登录、清空凭据或结束战网。

添加国服账号
1. 切到“国服”，添加容易识别的条目名称。邮箱、密码、将军令备忘按需填写。
2. 在管家选择对应国服条目，点“网页登录”。战网未运行时自动启动；已经有登录窗口时直接使用。无需再回管家点第二次准备。
3. 准备就绪后，在战网点一次“登录或注册”。新的登录请求会自动交给所选账号的内置窗口或专用 Chrome / Edge，再手动完成网页确认和必要验证。
4. 核对战网客户端进入的昵称，可展开“登录结果反馈（可选）”，点“登录成功，账号正确”。网页出现账号并不代表客户端已登录。
5. 新增其他账号时另建条目，重复以上步骤。每个账号的网页资料独立保存。
国服一键登录仍标为实验功能，已删除重复的启用勾选。正常登录账号并退出全部战网后，展开“国服一键登录（实验）”，点“记住这个账号”。以后可以直接点“一键登录（实验）”。
国服多开继续使用网页登录。一键切换要求正常退出所有战网；失效时使用网页登录重新认证，再登记。

添加外服账号
1. 切到“外服”，添加名称和登录邮箱，密码可不填。
2. 正常退出战网，点击“首次登录 / 重新认证”。手动登录所选邮箱，明确勾选“保持登录”。
3. 核对客户端昵称，从菜单选“退出”，不要选“退出登录”。
4. 下次选择该条目，点“切换并启动”。增加账号时重复以上步骤。
“首次使用 / 登录帮助”里提供退出后的保持登录检查。它只检查本地设置，不保证认证永久有效。
外服可选的“跳过战网运行检测”仍默认关闭，仅本次有效；成功启动不等于多账号同时登录成功。

解锁外服客户端
正常退出全部战网后，点击左下角“解锁外服客户端”。可先检查当前设置，再解锁国服与外服入口。
它补齐官方登录页的地区与语言选项，并备份原入口字段，支持撤销最近一次修改。
不替换战网程序，不合并国服和外服账号、购买内容或游戏进度。实际显示效果需在官方客户端核对。
详细流程见《解锁外服客户端说明.txt》。本功能仍标为实验。

资料、密码与备份
主密码可选，验证器二次验证可选。现有保护方式保持不变。
受保护的密码库需要解锁后才能查看或复制。密码显示和本工具复制的内容会按原规则自动隐藏／清除。
在“设置与备份”里备份资料、导入备份、打开资料目录，或选择战网位置。
完整备份包含账号备忘、网页资料及登记记录；恢复前提供预览并保留原目录。
备份绑定当前 Windows 用户，不能直接交给其他电脑解锁；不包含官方战网自身的登录凭据。
分享软件请发送“干净版.zip”，不要附带个人资料目录和备份。

验证范围
上一版完成 159 项相关检查，其中新增 18 项自动启动／等待／取消流程检查；另外核对现有界面、国服登记、浏览器选择、资料管理和密码保护。
本次完成 7 项启动与异步时序回归检查，以及 23 项工作区界面和 28 项密码保护检查。启动测试包含真实 Application.Run 流程，使用隔离的虚构资料；已核对编译。测试使用虚构账号和配置，没有修改实际战网配置，也没有重新进行真实服务器登录或新电脑实机验收。
登录状态提示中的“已确认”代表用户上次确认的结果，不保证持续有效。
