本管家源代码与构建
Source/src 和 Source/startup 包含本版本完整管家源码，Source/build.ps1 为构建入口。
示例：在 PowerShell 中进入 Source，运行：
  .\build.ps1 -Edition friends -DependencyDirectory .. -OutputDirectory .\build
Edition 可为 personal、friends、sponsored。
赞助版构建后，另复制软件根目录的 sponsor.json 至构建输出目录。
使用 Windows 的 .NET Framework C# 编译器，不需要 Codex。
