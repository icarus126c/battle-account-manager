战网账号管家 v1.14.7

三个版本使用相同的账号、密码保护和登录核心，均包含登录邮箱 / 密码 / 昵称的顶部复制入口，以及密码保护的跨电脑迁移包功能。

自用版
无广告。正常关闭旧管家，完整解压后打开“启动账号管家.exe”。
自动沿用当前 Windows 用户的 %LOCALAPPDATA%\BattleAccountManager 资料。
安装包中没有另放一份密码库或登录缓存；旧账号无需重新添加。

友情分享版
无广告、无账号数量限制。把未使用的原始 ZIP 发给朋友即可。
朋友完整解压后运行“启动账号管家.exe”，不需要 Codex 或开发环境。
没有旧资料的电脑首次启动为空列表；朋友自己添加账号和完成官方认证。
不要把运行过的软件文件夹、你的资料目录或备份发给朋友：运行后可能生成包含本机路径的引擎设置。

赞助版
登录功能与无广告版相同。可配置主界面底部的静态广告卡片，本版默认关闭。
明确标注“广告 / 赞助”；关闭偏好保存在本机，重启后继续生效，可用“显示赞助卡片”恢复。
当前没有真实广告合作方、推广链接、广告 SDK 或广告统计。
正式合作时请按“赞助配置说明.txt”填写本地 sponsor.json 后再重新发布干净包。

共同说明
三个版本在同一 Windows 用户下共用原账号资料目录；切换版本不会清空账号。
主密码、两步验证、密码复制和浏览器登录状态的行为不变。
Windows 10 / 11，.NET Framework 4.7.2 或更新版本；内置浏览器需要 WebView2 Runtime，也可选已安装的 Chrome / Edge。
国服一键登录仍标注实验；官方要求重新认证时使用网页登录。免网页多开不作稳定性承诺。
本工具由第三方提供，不代表暴雪、网易或 Battle.net 官方。

先做一次真实账号启动和切换核对，再扩大分享范围。
本轮没有更改真实账号配置、自动登录状态或浏览器 cookie。

自愿赞助（所有版本）
左下角的小字“支持作者”由用户主动打开，显示支付宝收款码。不开屏、不自动弹窗、不统计付款，也不影响登录功能。
分享包有意包含作者公开的收款二维码，但不包含使用者的账号、密码库、浏览器 Cookie 或登录缓存。

v1.14.7 新增跨电脑迁移包
设置与备份 → 换电脑 · 密码迁移包 → 导出迁移包 / 导入迁移包。
单独设置迁移密码，携带账号、密码和备注；不带浏览器和官方战网登录状态。
迁移包每次打开都需要密码，导入后沿用目标电脑的保护设置。详见“跨电脑迁移说明.txt”。
