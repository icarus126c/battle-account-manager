密码库保护实现与边界

主密码层：
PBKDF2-HMAC-SHA256 600000 次，随机 32 字节盐，分别派生 32 字节 AES 与 HMAC 密钥。
AES-256-CBC 使用随机 IV，HMAC-SHA256 认证整个头部及密文，认证通过后才解密。
内层保留 Windows 当前用户 DPAPI 加密。免主密码使用时仅保留这一层。
主密码不持久化，锁定和退出释放会话密钥；托管字符串和输入控件仍可能存在临时副本。

可选验证器：
标准 TOTP（RFC 6238），SHA-1、6 位、30 秒，容许前后一个周期的时钟偏差。
每次绑定生成独立的 160 位随机密钥，保存在主密码加密层之内，不另写明文配置。
8 个恢复码分别具有 80 位随机量，持久化仅保存其绑定密钥加盐后的 SHA-256 校验值。
验证通过后，消耗的时间步或恢复码状态写入当前主库，然后才开放访问，正常保存不能意外丢失这些设置。
启用两步验证的 BAMLOCK2 格式经过 HMAC 认证；老版本不认识该格式，改动版本头无法通过认证。
同一资料库正常使用时拒绝动态码重放、备用码重复使用。恢复历史文件也会恢复其历史消耗状态，离线备份无法抵御文件回滚。
连续五次失败后的三十秒暂停属于当前进程，重开应用会重置此节流状态。

范围：
两步验证用于本软件正常解锁和保护设置的访问校验，手机动态码不参与资料加密密钥派生。
如果另一个程序已经获得主密码和加密文件，仍可离线解密并取得绑定密钥；这不是服务器验证，也不是手机参与解密的硬件加密保护。
它不替代战网账号自己的将军令／验证器，不阻止已控制电脑或进程的恶意程序。
官方客户端凭据、浏览器 Cookie、旧版文件和历史导出不会被这次设置自动改写。
保持主密码或更改两步验证时，旧导出备份仍按原保护方式访问；移除保护也不解除历史文件的保护。
资料目前仍绑定 Windows 当前用户。

v1.14.0：额外的跨电脑迁移包
仅 .bammove 使用独立迁移密码加密且不叠加 Windows DPAPI；本机账号库和原备份仍绑定当前 Windows 用户。
不导出管家主密码、管家验证器密钥及恢复码；手工账号备忘会导出。
PBKDF2-HMAC-SHA256 600000 次 + 随机盐，AES-256-CBC + 随机 IV，HMAC-SHA256 验证后解密。
迁移密码保护导出文件；导入后沿用目标电脑的本机保护设置。完整边界见“跨电脑迁移说明.txt”。
