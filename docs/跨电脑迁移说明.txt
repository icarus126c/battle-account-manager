跨电脑迁移包 · v1.14.0

旧电脑：设置与备份 → 换电脑 · 密码迁移包 → 导出迁移包。
选择保存位置，自行设置并再次输入迁移密码，生成 .bammove 文件。
当前密码库若已锁定，须先按原保护方式解锁。

新电脑：完整解压 v1.14.0 或支持此格式的更新版本。
设置与备份 → 导入迁移包 → 输入迁移密码 → 查看账号预览 → 确认导入。
系统只添加缺失的账号条目，相同内部标识的条目不覆盖。重新手工添加过的同名账号可能被视为不同条目。

包含：全部国服和外服账号、账号密码、昵称、登录方式、手工将军令备忘、备注、收藏和隐藏条目。
不包含：浏览器 Cookie、官方战网凭据、一键登录登记、本机主密码、管家自身的验证器密钥和恢复码。
手工写在备注里的秘密也属于导出内容，请只把迁移包交给自己保管。

迁移密码：必须设置，10–256 个字符，可以与本机主密码不同；建议使用较长且独有的短句。
迁移包每次解密都需要它，遗忘后无法找回。密码不写入文件，不发送到服务器。
迁移包和密码应分开保管；不要把迁移包提交到 GitHub、网盘公开链接或软件分享包。
覆盖同名包时会保留旧的加密 .bak，旧包仍使用原来的迁移密码。

导入后的本机使用方式：沿用新电脑当前的保护设置。
如果新电脑处于免主密码模式，导入后也仍是免主密码模式；要限制查看和复制，请在“保护设置”启用主密码，必要时重新绑定验证器。
迁移密码保护文件，不会自动改掉本机主密码或关闭现有验证器。

新电脑还需重新完成官方战网和网页认证。一键登录状态不能通过账号密码迁移包复制过去。
确认账号及密码迁移完整前，请保留旧电脑与原资料。

与原备份的区别：
.bav / .bampack 是原有本机备份，仍受 Windows 当前用户加密保护。
.bammove 专用于换电脑，使用独立密码加密，不依赖 Windows 密钥，不包含浏览器缓存。

实现：BAMPORT1 格式，内部使用 PBKDF2-HMAC-SHA256 600000 次、随机 32 字节盐、AES-256-CBC 和随机 IV、HMAC-SHA256 验证后解密。
版本、格式用途和账号结构也会校验。解密前限制文件大小与派生工作量。
账号名称、数量及备注均位于密文内；扩展名和文件时间不保密。
导入后重新按目标电脑的本机保护方式保存。明文只在进程内短暂处理，不创建明文中间文件；托管字符串无法保证立即从内存抹除。

验证：已用虚构资料验证密码解密、正式强度、错误密码、文件篡改、参数限制、重复合并、原库与目标保护保留。
已确认密码解密后直接得到账号数据，不经过 DPAPI；尚未在第二台实体电脑上实测。
